    Capture three live artifacts from the running MongoDB. Read-only — no writes, no drops.

    1. mkdir -p pltu-tenayan-full-backup/docs/audit/.work

    2. Source MONGO_URL and DB_NAME from pltu-tenayan-full-backup/backend/.env:
       set -a; . pltu-tenayan-full-backup/backend/.env; set +a
       Confirm MONGO_URL is set and DB_NAME is set; if not, abort. Do NOT echo MONGO_URL to logs (it may carry credentials in URI form).

    3. List all collections in the database:
       mongosh "$MONGO_URL" --quiet --eval "db.getSiblingDB('$DB_NAME').getCollectionNames().sort().forEach(n =&gt; print(n))" \
         &gt; pltu-tenayan-full-backup/docs/audit/.work/mongo-collections.txt

    4. For each collection name produced above, run countDocuments and emit a JSON object { collection: count }:
       node -e '
         const { execSync } = require("child_process");
         const fs = require("fs");
         const url = process.env.MONGO_URL;
         const db  = process.env.DB_NAME;
         const names = fs.readFileSync("pltu-tenayan-full-backup/docs/audit/.work/mongo-collections.txt","utf8").trim().split("\n").filter(Boolean);
         const out = {};
         for (const n of names) {
           const cmd = `mongosh "${url}" --quiet --eval "db.getSiblingDB(\\"${db}\\").getCollection(\\"${n}\\").countDocuments({})"`;
           out[n] = parseInt(execSync(cmd).toString().trim(),10);
         }
         fs.writeFileSync("pltu-tenayan-full-backup/docs/audit/.work/mongo-counts.json", JSON.stringify(out, null, 2));
       '

       (If `node` is not installed in the working environment, fall back to a bash for-loop that builds the JSON via printf — the requirement is the JSON file, not the tool.)

    5. For each collection, capture exactly ONE sample document (top-level field names only, not full payload — we only need to verify the projection contract):
       mongosh "$MONGO_URL" --quiet --eval '
         const out = {};
         db.getSiblingDB("'"$DB_NAME"'").getCollectionNames().sort().forEach(n =&gt; {
           const doc = db.getSiblingDB("'"$DB_NAME"'").getCollection(n).findOne({});
           out[n] = doc ? Object.keys(doc).sort() : null;
         });
         print(JSON.stringify(out, null, 2));
       ' &gt; pltu-tenayan-full-backup/docs/audit/.work/mongo-samples.json

       This gives us, per collection, the keys of one document — enough to verify presence of `id` (UUID per CONS-projection-id-contract) and presence of `_id` (always present in storage; the contract is that the API filters it, not that it does not exist on disk).

    6. Sanity-check that the three files are non-empty and well-formed:
       wc -l pltu-tenayan-full-backup/docs/audit/.work/mongo-collections.txt
       jq -e '. | length &gt; 0' pltu-tenayan-full-backup/docs/audit/.work/mongo-counts.json
       jq -e '. | length &gt; 0' pltu-tenayan-full-backup/docs/audit/.work/mongo-samples.json

    Do NOT write or update any document. Do NOT drop or rename any collection. Phase 5 owns migration; this is read-only audit.
