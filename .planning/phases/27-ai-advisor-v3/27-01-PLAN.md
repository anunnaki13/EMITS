## Tasks

### Task 1 - Advisor Context, Confidence, And Limitations

Update `backend/services/operational_advisor.py`.

Implementation requirements:

- Consume `report.trend_analytics` and `report.data_quality`.
- Add top-level `trend_context`, `data_quality_context`, `confidence`, and `limitations`.
- Add trend/data-quality recommendations where thresholds are crossed.
- Preserve existing `recommendations`, `memo_draft`, and `guardrails` keys.

Acceptance:

- Advisor summarizes trend and data-quality findings using existing source slices.
- Sparse trend/data-quality caveats appear as limitations.

### Task 2 - Recommendation Groups And Owner Roles

Update recommendation construction in `backend/services/operational_advisor.py`.

Implementation requirements:

- Every recommendation includes `urgency`, `owner_role`, and `category`.
- Return `recommendation_groups` grouped by urgency with counts and item IDs.
- Existing severity/source/evidence fields remain intact.

Acceptance:

- UI and tests can group recommendations without parsing free text.

### Task 3 - Optional LLM Polish With Deterministic Fallback

Update advisor memo generation.

Implementation requirements:

- Default: no LLM call.
- Enable optional polish only with `ADVISOR_LLM_POLISH=1`.
- Use `get_ai_client()` only when enabled.
- Send bounded prompt containing only deterministic memo/context/recommendations/limitations.
- Catch LLM errors and return deterministic memo with guardrail fallback reason.
- Expose guardrails: `llm_enabled`, `llm_used`, `fallback_reason`, `unsupported_claims_refused`.

Acceptance:

- Tests prove normal path does not call live LLM.
- Tests prove optional polish can use fake client and failure falls back safely.

### Task 4 - Frontend Advisor Display

Update `frontend/src/pages/LaporanPage.js`.

Implementation requirements:

- Show advisor confidence badge.
- Show limitations/caveats when present.
- Render recommendation groups by urgency.
- Show owner role, evidence, and source slice per recommendation.
- Keep existing memo block.

Acceptance:

- Build passes and existing report flow remains usable.

### Task 5 - Tests, Verification, And Docs

Add `backend/tests/test_ai_advisor_v3.py`.

Coverage:

- advisor includes trend/data-quality context, limitations, and recommendation groups
- every recommendation is grounded with source slice and owner role
- default path does not call LLM
- optional polish uses fake client when explicitly enabled
- optional polish failure falls back to deterministic memo

- Do not expose API keys or secrets in prompts, logs, payloads, or docs.
- LLM polish must not add unsupported operational claims.
- Advisor must remain useful when LLM is disabled or unavailable.
- Tests must not consume live LLM budget.
- Keep response contract additive for existing frontend consumers.
