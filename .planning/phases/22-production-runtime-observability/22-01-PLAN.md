<objective>
Implement Phase 22: Production Runtime & Observability.

Deliver a safer production operating loop for EMITS:
- static nginx frontend is the documented/deployable production path;
- admins can see runtime status inside the app;
- operators can run one status/smoke command after deploy/restart;
- smoke checks produce auditable evidence;
- docs explain restart, rollback, nginx reload, smoke check, and failure triage.

This phase must not expose secrets and must not execute host shell commands from the web API.
</objective>

<interfaces>
New backend API:

```http
GET /api/admin/runtime/status
Authorization: Bearer <admin JWT>
```

Response shape:

```json
{
  "status": "healthy|warning|critical",
  "generated_at": "ISO-8601",
  "version": {
    "app_version": "string|null",
    "build_id": "string|null",
    "environment": "production|development|unknown"
  },
  "backend": {
    "status": "healthy",
    "api_prefix": "/api"
  },
  "database": {
    "status": "healthy|critical",
    "name": "string",
    "collections": 0
  },
  "frontend": {
    "status": "healthy|warning|unknown",
    "build_present": true,
    "static_root": "string|null"
  },
  "backup": {},
  "smoke": {
    "status": "pass|fail|unknown",
    "finished_at": "ISO-8601|null",
    "passed": 0,
    "failed": 0,
    "results": []
  },
  "disk": {
    "status": "healthy|warning|critical",
    "used_percent": 0
  }
}
```

```http
POST /api/admin/runtime/smoke-report
Authorization: Bearer <admin JWT>
```

Request body:

```json
{
  "started_at": "ISO-8601",
  "finished_at": "ISO-8601",
  "base_url": "http://127.0.0.1:8013",
  "frontend_url": "http://127.0.0.1",
  "results": [
    {"name": "backend health", "ok": true, "detail": "HTTP 200"}
  ]
}
```

Stored collection: `runtime_smoke_reports`, always read with projection `{"_id": 0}`.
</interfaces>

<threat_model>

| ID | Threat | Severity | Mitigation |
|----|--------|----------|------------|
| T22-01 | Runtime status leaks secrets such as Mongo URL, JWT secret, API keys, or tokens. | High | Return allowlisted fields only; add tests that scan response JSON for secret-like keys and values. |
| T22-02 | Non-admin users access runtime or smoke report endpoints. | High | Use `require_role(["admin"])`; add role/auth test coverage. |
| T22-03 | Web runtime endpoint executes host commands or exposes command output. | High | Backend service must use Python-level checks only; host checks stay in `ops/scripts/runtime_status.sh`. |
| T22-04 | Smoke report persistence becomes trusted security evidence that can be spoofed. | Medium | Treat reports as operational evidence only; admin-only POST; include generated timestamps and raw check results. |
| T22-05 | Static frontend cutover breaks API base URL or React Router fallback. | Medium | Keep nginx `/api/` proxy and `try_files $uri /index.html`; run smoke check against frontend URL and backend URL. |

</threat_model>
