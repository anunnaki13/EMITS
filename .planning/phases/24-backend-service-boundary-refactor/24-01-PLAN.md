## Tasks

### Task 1 - Shared Query Helpers

Create `backend/services/query_filters.py`.

Move/consolidate:

- period/date matching
- supplier matching with escaped regex
- mode normalization/matching
- match merging
- sum/avg aggregation helpers
- safe float
- aging days
- source slice builder

Acceptance:

- Existing routers can import helpers without circular imports.
- Helpers are deterministic for `all`, `YYYY`, `YYYY-MM`, explicit date ranges, supplier, and mode.

### Task 2 - Management Report Service

Move management report calculations from `backend/routers/reports.py` into `backend/services/management_reports.py`.

Implementation requirements:

- Preserve `build_management_report(period, supplier, date_from, date_to, user)` signature or provide a compatible import.
- Keep `/api/reports/management` response shape unchanged.
- Use shared query helpers where practical.

Acceptance:

- `routers/reports.py` becomes a thin FastAPI wrapper.
- `test_management_reports.py` still passes.

### Task 3 - Dashboard Metrics Service

Move dashboard calculations from `backend/routers/dashboard.py` into `backend/services/dashboard_metrics.py`.

Implementation requirements:

- Provide `build_dashboard_operational(period, supplier, mode, user)`.
- Provide `build_dashboard_stats(user)`.
- Provide `build_dashboard_advanced(year, month, moda, user)`.
- Preserve response shapes and `DashboardStats` behavior.

Acceptance:

- `routers/dashboard.py` becomes thin endpoint wiring.
- Dashboard operational and advanced tests still pass.

### Task 4 - Operational Advisor Service

Move operational advisor recommendation and memo logic from `backend/routers/ai_intelligence.py` into `backend/services/operational_advisor.py`.

Implementation requirements:

- Provide `build_operational_advisor(period, supplier, date_from, date_to, user)`.
- Use `services.management_reports.build_management_report`.
- Preserve deterministic no-live-LLM behavior.
- Keep `build_contextual_ai_context` untouched unless helper imports are needed.

Acceptance:

- `/api/ai/advisor/operational` route is a thin wrapper.
- Existing AI endpoint and management report tests still pass.

### Task 5 - Service Boundary Tests

Add `backend/tests/test_service_boundaries.py`.

Coverage:

- direct service call for management report
- direct service call for dashboard operational builder
- direct service call for operational advisor builder
- route compatibility remains covered by existing tests

Acceptance:

- Tests use isolated test DB and no live secrets.
- Tests clean up seeded records by marker.

## Threat Model

- Regex filters must escape user-provided supplier/search values.
- Service extraction must not bypass FastAPI auth dependencies; routers remain the auth boundary.
- No secrets or test credentials may be committed.
- Response contracts must remain backward compatible.
