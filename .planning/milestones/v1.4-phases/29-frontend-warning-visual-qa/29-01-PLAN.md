# Plan 29-01: Frontend Warning Cleanup And Visual Smoke Gate

## Objective

Remove legacy React hook warning debt where safe, add a warning-budget build script, and introduce Playwright visual smoke coverage for the five v1.4 frontend QA surfaces.

## Tasks

1. Normalize legacy hook warnings.
   - Add `useCallback` to AI, CRUD, stock usage, merit order, and settings fetch loaders.
   - Preserve filter-driven reload, post-save refresh, and initial-load behavior.

2. Add build warning budget enforcement.
   - Add a frontend script that runs the production build and parses `react-hooks/exhaustive-deps` warnings.
   - Compare parsed warnings with `docs/quality/REACT_HOOK_WARNINGS.md`.
   - Add `npm run build:checked`.

3. Add Playwright visual smoke coverage.
   - Add Playwright dependency/config if absent.
   - Add smoke tests for dashboard, management report, data quality, dispute monitor, and settings runtime status.
   - Cover desktop and tablet projects.
   - Capture screenshots and assert required anchors, non-empty content, no horizontal overflow, and obvious text collision detection.

4. Update quality documentation.
   - Refresh React hook warning register to match actual build output.
   - Add visual smoke usage documentation and environment variables.

5. Verify and close.
   - Run frontend build.
   - Run warning-budget build check.
   - Run Playwright test discovery.
   - Update Phase 29 summary, verification, roadmap, requirements, and state.

## Acceptance Criteria

- `npm run build` passes.
- `npm run build:checked` passes with register parity.
- `npx playwright test --list --config=playwright.config.js` lists both desktop and tablet coverage for all five pages.
- Phase 29 artifacts document any skipped full-browser execution prerequisites.
- QA4-01..QA4-05 are marked complete only after verification evidence is recorded.
