# Plan 30-01: Metadata Backfill, Archive Index, And Planning Hygiene Gate

## Objective

Close GSD metadata and archive hygiene debt by making validation metadata explicit, archived phases discoverable, current progress state checkable, and future phase docs templated.

## Tasks

1. Backfill validation metadata.
   - Add `nyquist_status: legacy_exception` frontmatter to archived validation docs that predate the metadata standard.
   - Preserve original validation content below the frontmatter.

2. Index the v1.3 phase archive.
   - Add `.planning/milestones/v1.3-phases/INDEX.md`.
   - Link phase directories, summary counts, validation docs, and verification docs.
   - Cross-link the index from `.planning/MILESTONES.md`.

3. Add future phase templates.
   - Create `.planning/templates/PHASE-SUMMARY-TEMPLATE.md`.
   - Create `.planning/templates/PHASE-VERIFICATION-TEMPLATE.md`.
   - Create `.planning/templates/PHASE-VALIDATION-TEMPLATE.md`.

4. Add planning hygiene check.
   - Create `scripts/check_planning_hygiene.py`.
   - Check validation metadata, archive index coverage, active phase workspace boundaries, templates, and current next-step state.

5. Verify and close Phase 30.
   - Run planning hygiene check and diff whitespace check.
   - Create summary and verification docs.
   - Mark META4-01..04 complete and route the project to Phase 31.

## Acceptance Criteria

- `python3 scripts/check_planning_hygiene.py` exits 0.
- `git diff --check -- .planning scripts/check_planning_hygiene.py` exits 0.
- v1.3 archived phase docs are discoverable from an index.
- Current state points to Phase 31 after Phase 30 closure.
- Phase 30 has SUMMARY, VALIDATION, and VERIFICATION artifacts.
