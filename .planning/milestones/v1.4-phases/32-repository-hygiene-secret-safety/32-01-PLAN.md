# Plan 32-01: Repo Hygiene Gate And Cache Ignore Cleanup

## Objective

Make repository release hygiene explicit and enforceable: document allowed
local-only dirt, prevent frontend build-cache ignore churn, and keep credential
scanning wired into a single repo hygiene command.

## Tasks

1. Cache ignore cleanup.
   - Replace individual frontend webpack pack entries in `.gitignore` with
     directory-level cache ignore rules.

2. Repo hygiene gate.
   - Add `scripts/check_repo_hygiene.py`.
   - Run the existing credential scanner from the new gate.
   - Allow only documented unstaged local-only paths.
   - Block staged local-only files, unexpected dirty files, and pack-entry
     `.gitignore` churn.

3. Documentation.
   - Add `docs/operations/REPO_HYGIENE.md`.
   - Link the command from `docs/operations/PRODUCTION_RUNBOOK.md`.

4. Verification.
   - Add unit coverage for status classification.
   - Run credential, syntax, pytest, and repo hygiene checks.
   - Update Phase 32 validation/verification/summary docs and mark REPO4
     complete.

## Acceptance Criteria

- `python3 scripts/check_repo_hygiene.py` passes with only documented local-only
  dirt in the worktree.
- `scripts/check_credentials.sh` remains part of the hygiene gate.
- `.gitignore` no longer contains individual frontend cache pack paths.
- Documentation names the local-only allowlist without exposing secrets.
