## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client JWT -> /api/ai/conversations/* | Untrusted bearer; Depends(get_current_user) validates |
| user_id from JWT -> ai_chat_history filter | Authorization decision boundary |
| user content body -> LLM payload | Untrusted prompt material crosses to OpenRouter |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-04-01 | Elevation of Privilege | Cross-user conversation access | mitigate | Every endpoint filters MongoDB query by user_id from JWT (RESEARCH Security Domain V4); test_get_messages negative case asserts 404 on cross-user fetch |
| T-06-04-02 | Information Disclosure | LLM budget leak via test backend hitting live OpenRouter | mitigate | AI_FAKE=1 in conftest._backend_lifecycle (Phase-4 contract); existing LLM-budget guard test continues to pass under Phase-6 changes; verified in Task 06-04-02 |
| T-06-04-03 | Tampering | Empty content body causes LLM to hallucinate "user said nothing" | mitigate | content.strip() empty -> HTTPException 422 (ASVS V5 input validation) |
| T-06-04-04 | Spoofing | session_id collision between users | mitigate | session_id format includes user_id prefix (tenayan-ai-{user_id}-{uuid4}); even on accidental UUID collision the user_id filter prevents access; uuid4 collision probability is negligible |
| T-06-04-05 | Tampering | Prompt injection via user chat message | accept | User content placed in user role (not system); OpenRouter model has instruction-following; out-of-scope for milestone v1 per RESEARCH Security Domain |
</threat_model>
