## Method

Per D-02 (every endpoint must be spot-checked against live behavior) and D-08
(LLM-key dependent / destructive endpoints are `verified: schema-only`):

1. The auto-generated table in `API_REFERENCE.md` is itself live-verified —
   it is a deterministic projection of `/openapi.json` and is regenerated
   on demand. Drift is caught by `python3 scripts/regenerate_api_reference.py
   && git diff --exit-code API_REFERENCE.md`.
2. On top of that, 5 representative endpoints across role tiers and
   pagination contracts are probed end-to-end against the live backend to
   prove the table reflects real behaviour, not just shape.
3. Endpoints whose live execution is gated by external services (LLM API
   keys) or whose execution would mutate / destroy data are explicitly
   marked `verified: schema-only` and deferred to Phase 4 TEST-* with
   isolated fixtures.

### Coverage rationale (why 5 representatives, not all 95)

The 5 endpoints exercise the union of contract-relevant behaviours:

- **Public vs Bearer:** #1 covers public; #2-5 cover Bearer.
- **Pagination envelope:** #3 specifically verifies the
  `{items,total,page,page_size,total_pages}` shape locked by ADR-008.
- **Tri-role vs admin-only:** #5 hits the lone admin-only read in the
  surface; #2-4 are tri-role.
- **Module spread:** auth, dashboard-summary (kpis), data-collection list
  (vessels), and admin-management (users) cover the four operational
  classes.

The remaining 90 method/path pairs are covered by:

1. The schema fetch itself: `/openapi.json` is the live router — every entry
   in the auto-generated table is, by construction, present in the live
   FastAPI app.
2. The full Phase-2 regression suite (`backend/tests/`) which exercises
   `vessels`, `barges`, `trucking`, `biomassa`, `po-batubara`, `merit-order`,
   `coa-reconciliation`, `dashboard/advanced` modules behaviourally.

## Reproducibility

To re-run this spot-check (idempotent; read-only against live):

```bash
cd pltu-tenayan-full-backup

# Source admin creds (gitignored file)
export TEST_ADMIN_EMAIL="$(grep -A 3 '^## Akun Admin' memory/test_credentials.md | grep '^- Email:' | head -1 | sed 's/^- Email:[[:space:]]*//')"
export TEST_ADMIN_PASSWORD="$(grep -A 3 '^## Akun Admin' memory/test_credentials.md | grep '^- Password:' | head -1 | sed 's/^- Password:[[:space:]]*//')"

# Login → token
TOKEN="$(curl -fsS -X POST http://localhost:8013/api/auth/login \
  -H 'Content-Type: application/json' \
  -d "$(python3 -c 'import json,os;print(json.dumps({"email":os.environ["TEST_ADMIN_EMAIL"],"password":os.environ["TEST_ADMIN_PASSWORD"]}))')" \
  | python3 -c 'import json,sys;print(json.load(sys.stdin)["access_token"])')"

# 5 probes
echo -n "1. GET /api/health: ";        curl -sS -o /dev/null -w "%{http_code}\n" http://localhost:8013/api/health
echo -n "2. GET /api/auth/me: ";       curl -sS -o /dev/null -w "%{http_code}\n" http://localhost:8013/api/auth/me -H "Authorization: Bearer $TOKEN"
echo -n "3. GET /api/vessels env: ";   curl -fsS "http://localhost:8013/api/vessels?page=1&page_size=2" -H "Authorization: Bearer $TOKEN" \
                                          | python3 -c 'import json,sys;d=json.load(sys.stdin);need={"items","total","page","page_size","total_pages"};print("OK" if need<=set(d.keys()) else f"MISSING: {need-set(d.keys())}")'
echo -n "4. GET /api/coa-reconciliation/kpis: "; curl -sS -o /dev/null -w "%{http_code}\n" http://localhost:8013/api/coa-reconciliation/kpis -H "Authorization: Bearer $TOKEN"
echo -n "5. GET /api/users (admin): "; curl -sS -o /dev/null -w "%{http_code}\n" http://localhost:8013/api/users -H "Authorization: Bearer $TOKEN"

# Cleanup
unset TEST_ADMIN_EMAIL TEST_ADMIN_PASSWORD TOKEN
```

Expected output (all 5 lines): `200`, `200`, `OK`, `200`, `200`.
